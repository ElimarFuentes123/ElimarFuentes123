# Car Edits

Toolkit para sa car edits.

| Tool | Gamit | Install |
|---|---|---|
| FFmpeg | cuts, mix, export | system (`ffmpeg`) |
| Remotion | video sa React (`remotion/`) | `npm i` |
| HyperFrames | captions + graphics, beat detection (`car-edits/`) | `npm i` |
| Whisper | subtitles (faster-whisper) | `pip install -r requirements.txt` |
| Groq | Taglish transcription/understanding | `pip install -r requirements.txt` + `GROQ_API_KEY` |
| yt-dlp | download references | `npm run yt -- <url>` |

Setup: `npm i && pip install -r requirements.txt`
