## Note on the voice (answer honestly at upload)
The narrator is an **AI copy (clone) of a real person's voice**, the MP3 you chose.
Because of that, the safe and honest choice is:
- **YouTube** → at upload, "Altered or synthetic content" → **Yes**
- **TikTok** → when posting, More options → **"AI-generated content"** → On

This label does not hurt reach. Not labeling can get videos taken down.

## Steps
### TikTok (5 min)
1. Use a new Gmail just for this channel (e.g. `alastres.stories@gmail.com`).
2. TikTok app → Profile → ☰ → Add account → Sign up with that Gmail.
3. Username: `alastres.stories`
4. Edit profile → Change photo → `profile_picture.png` → Name `ALAS TRES` → Bio (above).

### YouTube (5 min)
1. Sign in to YouTube with the same Gmail.
2. Profile picture → **Create a channel** → Name `ALAS TRES`, handle `@alastres.stories`.
3. YouTube Studio → Customization:
   - Branding → Picture `profile_picture.png`, Banner `youtube_banner.png`
   - Profile → Description + Links (above)
4. Settings → Channel → keywords, country, audience (above).
5. Verify your phone at **youtube.com/verify**. It unlocks custom thumbnails and longer videos.
