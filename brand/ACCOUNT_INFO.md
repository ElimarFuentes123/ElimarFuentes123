## Steps
### TikTok
1. TikTok app → Profile → ☰ → Add account → Sign up (gumamit ng bagong email, hal. hiwalay na Gmail).
2. Ilagay ang birthday mo, tapos username `v12.motion`.
3. Edit profile → Change photo → `profile_picture.png` → Name `V12 MOTION` → Bio sa itaas.

### YouTube
1. Gumawa ng bagong Gmail (hal. v12motion.edits@gmail.com) — o gamitin ang Gmail na pinang-TikTok mo.
2. youtube.com → profile icon → Create a channel → Name `V12 MOTION`, handle `@v12motion`.
3. YouTube Studio → Customization:
   - Branding → Picture: `profile_picture.png`, Banner: `youtube_banner.png`
   - Basic info → Description + Links
4. Settings → Channel → keywords, country, audience (sa itaas).
5. I-verify ang phone (youtube.com/verify) para makapag-upload ng mahigit 15 min at custom thumbnails.
